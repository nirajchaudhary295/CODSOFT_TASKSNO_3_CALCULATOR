# 🧮 Professional Calculator

A modern, responsive, and user-friendly **Calculator Web Application** built using **HTML, CSS, and JavaScript**.

This project was developed as **Level 1 – Task 3** to demonstrate fundamental web development concepts including DOM manipulation, event listeners, CSS Grid, JavaScript functions, conditional logic, and arithmetic operations.

---

## 🚀 Live Demo

🔗 **Live Demo:** https://shekhar-himanshu-dbg.github.io/CODSOFT_TASKSNO_3_CALCULATOR/




---

## 📌 Project Overview

The Professional Calculator provides a clean and intuitive interface for performing basic mathematical operations.

Users can perform:

* Addition
* Subtraction
* Multiplication
* Division
* Modulo operations
* Decimal calculations
* Clear/reset operations
* Delete operations
* Keyboard-based calculations

The application is designed to be responsive and works smoothly across desktop, tablet, and mobile devices.

## ✨ Features

### 🎯 Core Features

* ➕ Addition

### ⌨️ Keyboard Support

The calculator also supports keyboard input.

| Key         | Function       |
| ----------- | -------------- |
| `0 - 9`     | Enter numbers  |
| `+`         | Addition       |
| `-`         | Subtraction    |
| `*`         | Multiplication |
| `/`         | Division       |
| `%`         | Modulo         |
| `.`         | Decimal        |
| `Enter`     | Calculate      |
| `Backspace` | Delete         |
| `Escape`    | Clear          |

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/nirajchaudhary295/CODSOFT_TASKSNO_3_CALCULATOR
```

### 2. Navigate to the project directory

```bash
cd calculator-project
```

### 3. Open the project in VS Code

```bash
code .
```

### 4. Run the project

Open `index.html` using:

* VS Code Live Server, or
* Your preferred web browser.
